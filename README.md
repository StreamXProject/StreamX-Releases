# StreamX public extension downloads

The website and app releases are maintained in [StreamX](https://github.com/StreamXProject/StreamX).

- [Website](https://streamxproject.github.io/StreamX/)
- [App releases](https://github.com/StreamXProject/StreamX/releases/latest)
- [Public skins and icons](https://github.com/StreamXProject/Skins/releases)
- [Extension catalogue](https://streamxproject.github.io/StreamX-Releases/extensions/index.json)

This repository keeps public downloads for private plugins, existing Automix packages, and historical downloads. Existing installed apps can continue using its catalogue and old asset URLs.

The catalogue links directly to Skins release APKs and icons. **Sync direct skin links** refreshes those links hourly or on manual dispatch, preserving plugin entries and refusing skin downgrades. No cross-repository publishing credential is needed for this sync.

`docs/index.html` redirects the former website address to StreamX. Existing catalogue and icon URLs under `docs/extensions/` remain available.
